# 回归与人工验收流程

状态以 test-report.md 为准。本文件描述步骤，列入计划不代表已经验证。所有网站测试使用独立配置文件和无登录状态，不操作真实账号数据。

## 可控页面

启动 `npm run serve`，打开 http://localhost:4173 。初始为站点亮色。

| 场景 | 操作 | 判定 |
|---|---|---|
| 基本视觉 | 观察正文、层级、代码、三种语义色、透明嵌套和原生深色卡片 | 主要文字可读，颜色有区分，媒体原样 |
| 表单 | 填备注、切选项、复选框，保持焦点并切全局开关 | 输入、焦点、选择、滚动不丢失，无刷新 |
| 交互 | 菜单 → SPA 路由 → 弹窗 → 输入 → 关闭 | 布局、点击与焦点正常 |
| 动态 | 追加100项 → 修改已有颜色 → 移除 → 重复 | 增量内容转换，原样模式下恢复站点的新颜色 |
| 网站主题 | 站点亮 → 暗 → 亮；再强制转换；关闭插件 | 自动状态正确，关闭恢复站点当前主题 |
| frame | 同源 localhost 与跨源 127.0.0.1 frame 输入；将顶层 localhost 设原样 | 两个 frame 均遵循顶层规则；记录任何加载失败，不把空 frame 当通过 |
| Shadow DOM | 观察已有开放组件、新增开放组件和关闭恢复 | 按测试覆盖报告；封闭根不承诺 |
| CSS 动态 | insertRule / style.textContent / 变量 / !important 行内样式 | 保留变量作用域；关闭后保留网站后续修改 |
| 批量 | `?large`，5000节点、连续滚动、动态改色、切换100次 | 不出现持续卡顿，无残留样式，按预算测量资源趋势 |
| 媒体 | 对照图片截图、Canvas像素；播放本地生成视频再切换 | 像素不反色、播放不中断；需将“播放测试”与只检查 filter 区分 |
| 跨标签 | 开两个 localhost 路径和一个 127.0.0.1 页面 | 主机规则隔离，全局颜色和开关同步 |
| 持久化 | 改配色和网站规则 → 关闭浏览器 → 同 profile 重启 | 设置和行为保留 |
| 恢复颜色 | 指定网站规则，再恢复默认配色 | 网站规则仍保留 |
| 受限页 | Chrome 内部页、商店、PDF、权限限制 | Popup 给出原因，不只显示开启 |
| 局部 PDF | 普通 HTML 页插入 PDF embed 再开关转换 | 周围 HTML 继续转换，局部对象保留；不代表内置 PDF 阅读器已适配 |

## 性能

见 performance-budget.md 和 scripts/performance.mjs。禁止并发运行其他自动化，以免 CPU/RSS 干扰。保留原始样本、设备、浏览器版本。时间度量采用 CSS/渲染帧代理而非首屏录像；JS GC 堆不等于标签页全部内存，因此另录进程树 RSS。长时间验收应至少连续运行数小时，并单独报告，不能由百次切换代替。
