# 文本选中高亮修复

日期：2026-10-08。

网页自定义的 `::selection` 原先走普通背景映射，浅色或半透明的选中底色转换后容易接近页面背景；插件原有的默认选中色又会被网站规则覆盖。

选中区域现在使用独立的不透明配色。默认暗色背景下采用浅蓝色 #8ab4f8 和深色文字 #101828，与默认页面背景的对比度约 8.10:1，文字与选中底色的对比度约 8.42:1。自定义背景较亮时，按与背景的对比度选择深蓝色 #264f78 和白色文字。配对文字颜色独立于普通正文设置，同时覆盖文字填充颜色并清除选中文字阴影。

转换网站规则时保留选择器优先级、媒体查询、层和嵌套作用域，单独处理选择伪元素；混合选择器列表中的普通元素继续使用原有背景映射。未增加 DOM 扫描、鼠标监听或网络请求。关闭插件、保持原样模式及自动跳过的原生暗色页面仍使用网站自身样式。
