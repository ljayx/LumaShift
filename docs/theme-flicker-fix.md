# 自动模式主题闪烁修复

验证日期：2026-10-08。

DuMate 技能页面的卡片使用 0.2 秒 CSS 过渡。LumaShift 自动模式通过临时禁用生成样式、读取计算背景色来识别原主题。禁用样式会启动背景色过渡，采样可能读到尚未退出的插件暗色，将原本亮色的网站误判为原生深色。后续样式更新再次触发检测，导致引擎反复启停。

修复由 ThemeEngine.withOriginal 统一管理采样：在同步采样期间临时禁止 CSS 过渡，恢复生成样式后刷新布局，再移除临时规则。inspectOriginal 不再重复禁用样式，避免把采样保护规则一并关闭。

浏览器对照使用相同页面和每 240 毫秒一次的样式更新，分别打包修复前 HEAD 和当前的 content、proxy、engine、detection 模块。测试使用模拟扩展消息接口，不修改个人 Chrome 的扩展配置。

- 修复前：2.4 秒、96 次采样；状态出现 native 和 active；捕获 9 次引擎启停事件，背景在白色与暗色之间变化。
- 修复后：2.4 秒、96 次采样；全部为 active，背景始终为 rgb(24, 28, 36)，没有引擎启停事件。
- 网站主动切换暗色：状态为 native，背景 rgb(22, 28, 37)，生成样式数量为 0。
- 网站切回亮色：恢复 active 和插件暗色。
- 关闭插件：状态为 off，恢复 rgb(255, 255, 255)，生成样式数量为 0，原有 transition-duration: 0.2s 保留。
- npm test：18 项单元测试通过；npm run build：通过，dist 已更新。

持久回归用例位于 tests/fixtures/theme-transitions.html 和 scripts/e2e.mjs。本次执行了上述浏览器定向验证，未运行完整 e2e 套件。现场技能卡片的过渡规则已核对；Chrome 扩展管理页受浏览器工具访问策略限制，已安装扩展尚未由本次任务重新加载，真实 URL 的新版最终验证仍需重载扩展后进行。
